ANIOXAZ Release Log
===================

Version 1.0.0
-------------
- Initial project package structure and CLI scaffold.
- Basic Textual app shell and editor flow.
- Prototype local-model workflow and basic project scaffolding.
- Initial packaging metadata and install path set up.

Version 1.0.1
-------------
- Fixed the startup crash caused by a naming conflict with Textual's internal logger.
- Renamed the custom app log method from `log` to `append_log` to avoid overriding Textual's `App.log` object.
- Updated all affected call sites across the app runtime.
- Bumped package version to 1.0.1 in project metadata and package `__version__`.
- Updated README installation instructions to reference the correct wheel filename.
- Confirmed the project passes tests and builds successfully with `python -m pytest -q` and `python -m build`.

Version 1.0.2
-------------
- Model loading now validates the requested file path before checking the optional model dependency.
- Application logging now works safely before the Textual screen is mounted.
- Added behavioral FRS tests for model loading, execution, editor interfaces, terminal commands, AutoHeal, and pipeline availability.
- Confirmed all ten requirements are mapped, tested, and satisfied by NIWOEC 2.1.0.
- Added the FRS verification report and NIWOEC improvement recommendations.

Maintenance notes
-----------------
- This release keeps the project installable and launchable as a packaged CLI.
- The app remains designed for local/offline model workflows and editor-based coding assistance.
- Use `anioxaz` after installation to launch the UI.
